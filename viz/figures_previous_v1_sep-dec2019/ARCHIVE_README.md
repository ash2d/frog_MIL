# Archived: v1, Sep–Dec 2019 audio only

Snapshot of the study before the Feb–Apr 2019 recordings were added (archived 2026-09-25).

- Audio: 3414 clips, 2019-09-23 → 2019-12-03 (1707 hour-bags, 78,522 windows)
- Test set: 216 bags (G. chrysosticta 18+, O. berdemenos 62+)
- Best model: `linear-ord2-s2/max`, macro AP 0.809 [0.707, 0.894]

The five v1 folders belong together: `results_`, `viz/figures_`, `runs_`, `outputs_`,
`embeddings_previous_v1_sep-dec2019/`. Paths inside the generated files (`runs/`, `outputs/`,
`embeddings/`) refer to these folders' original names. The current results (v2, Feb–Apr +
Sep–Dec 2019) are in `results/`, `viz/figures/`, `runs/`, `outputs/` and `embeddings/`. Test
sets differ between v1 and v2, so compare them only loosely, not as paired deltas.
